# APEX Mega-Skills & Hierarchical Amplification

We employ **Hierarchical Skill Amplification**. Intelligence compounds upward. A subagent invoking a Mega-Skill automatically inherits the exact operational protocols of every base skill beneath it, amplifying its reasoning power without manual context-stuffing.

## The Amplification Hierarchy

### Level 4: The Apex Node
* **`apex-sovereign-supreme`**: The master orchestrator. Amplifies all 7 Mega-Skills below it.

### Level 3: The 8 Mega-Skills (Persona Level)
These bind directly to Diamond Grid personas:
1. **`apex-command-core`** (Architect) ➔ Amplifies orchestration, execution modes.
2. **`apex-connector-mesh`** (Connector) ➔ Amplifies auth, ai-gateway, multi-protocol meshes.
3. **`apex-device-interface`** (Hardware) ➔ Amplifies device telemetry and physical bridges.
4. **`apex-litigation-colossus`** (Litigator / Justice) ➔ Amplifies bottom-to-top 7-pillar case builds, void decree strikes, FRE 901/902 exhibit packages.
5. **`apex-legal-intelligence`** (Forensics / Counsel) ➔ Amplifies 15-step reasoning, authority hierarchy, evidence authentication.
6. **`apex-memory-substrate`** (Archivist) ➔ Amplifies Aspen-Grove, unified memory connects.
7. **`apex-engineering-excellence`** (Implementer) ➔ Amplifies verification, zero-fake-truth, benchmarks.
8. **`apex-specialist-registry`** (Cartographer) ➔ Amplifies marketplace discovery, library-of-links.

### Level 2: Domain Skills
e.g., `memory-unified`, `workflow`, `ai-gateway`. They orchestrate Level 1 skills.

### Level 1: Base Primitives
e.g., `auth`, `env-vars`, `token-optimizer`. Highly focused, single-purpose constraints.

## Amplification Protocol (Execution)
When a subagent is spawned into the Diamond Grid (e.g., the Implementer), the `activate_all_skills` engine performs a **Deep-Resolve**:
1. It reads the target Mega-Skill (`apex-engineering-excellence`).
2. It recursively parses the `dependencies` / composed sub-skills down to Level 1.
3. It bundles the constraints into a unified, token-optimized context payload.
4. The agent wakes up with the combined, amplified intelligence of 15+ sub-skills fused into a single persona.
