# Ai Sdk

## Purpose
Provides bindings to the Vercel AI SDK for:
- Streaming text generation with backpressure.
- Structured output (JSON schema validation on LLM responses).
- Tool-calling patterns compatible with the APEX connector mesh.

## When to Use
- Building chat interfaces or streaming UIs.
- Generating structured JSON from LLM calls.
- Integrating with Next.js server actions.
