# Nextjs Ecosystem

## Covered Patterns
- App Router vs Pages Router architecture decisions.
- Server Components, Client Components, and the `use client` boundary.
- Server Actions for form handling and mutations.
- Route Handlers (API routes) with proper error handling.
- ISR, SSG, SSR rendering strategy selection.
- Middleware for auth, redirects, and request rewriting.

## When to Use
When building, debugging, or optimizing Next.js applications in the APEX estate.
