# Chat Sdk

## Purpose
Provides the agent with knowledge of chat SDK patterns:
- Message threading and conversation state.
- Streaming responses with typing indicators.
- Multi-modal message support (text, images, files).

## When to Use
When building or modifying chat-based interfaces that need real-time streaming and structured message handling.
